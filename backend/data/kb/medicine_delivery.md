# Medicine Ordering and Delivery

## Prescriptions
Prescription medicines need a valid prescription from a registered medical practitioner. The pharmacist verifies the prescription before the order is packed. Orders with an unclear prescription are put on hold and the user is called.

## Delivery times
Express delivery in select pincodes delivers within 60 minutes for in-stock items. Standard delivery takes 1-3 days depending on the pincode. The live order status shows: placed, prescription verified, packed, dispatched, out for delivery, delivered.

## Delayed orders
If an order is delayed past its promised time, the user can request a callback. If an item is out of stock, the user is offered a substitute only with the same composition and strength, and only after the user approves it.
